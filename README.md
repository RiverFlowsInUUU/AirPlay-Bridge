# AirPlay Bridge

<p align="center">
  <img src="src/icons/preview_connected.png" width="128" alt="AirPlay Bridge">
</p>

把 Windows 的系统声音实时串流到 AirPlay 2 设备，跑在托盘里。

TuneBlade 在 HomePod OS 27 失效后的替代方案。

## 安装

1. 安装 [VB-Audio Virtual Cable](https://vb-audio.com/Cable/)（免费，装完需重启）
2. 从 [Releases](https://github.com/RiverFlowsInUUU/AirPlay-Bridge/releases/latest) 下载 exe，双击运行

Windows 10 / 11，64 位。程序是单文件，不需要安装，不需要运行库。

> 首次运行 Windows 可能拦一次，点「更多信息」→「仍要运行」。

## 首次运行

- 询问是否开机自动启动（只问一次，之后可在菜单里改）
- 扫描局域网并连接找到的设备
- 检查网络放行是否有效，失效时提示一键修复

之后每次启动都直接连上次用过的设备。

## 声音输出

连接后，声音只从 AirPlay 设备出，电脑保持安静，断开时自动还原。

## 特性

- 自动发现局域网内的设备
- 断线自动重连，设备换 IP 也能找回
- 被强杀后，下次启动自动恢复音频设备
- 延迟 / 音量 / 音质 / 静音待机可调
- 静音自动待机：长时间没声音时断开让设备熄屏，一有声音立刻回来
- 开机自启，记住上次设置
- 菜单里可检查更新
- 同一时间只允许运行一个，避免互相打断播放

## 使用

托盘图标左键或右键都能打开菜单。

```
✓ 已连接
  <设备名>
  <设备 IP>
────────────────
  断开
  修复连接问题（需要管理员权限）
  选择设备  ›
  延迟  150ms  ›
  音量  45%  ›
  音质  至臻  ›
────────────────
  静音自动待机  ›
  开机自启
  打开日志文件夹
  检查更新
  关于 AirPlay Bridge vX.Y.Z
────────────────
  退出
```

网络放行正常时，点「修复连接问题」会直接告诉你不需要处理。

## 可调项

| 项 | 范围 | 生效 |
|---|---|---|
| 延迟 | 120 – 150 ms，4 档 + 滑块 | 重连后 |
| 音量 | 5 – 100%，20% 一档 + 滑块 | 立即 |
| 音质 | 0 – 100%，5 档 + 滑块 | 重连后 |
| 静音自动待机 | 0 – 20 秒，4 档 + 无极滑块（0 = 关闭） | 立即 |

延迟档位：120 / 130 / 140 / 150 ms（150 推荐）。

音质档位：快速 / 标准 / 高 / 极高 / 至臻（默认）。

待机档位：5 / 10 / 15 / 20 秒（5 秒默认）；滑块为 0 – 20 秒无极调节，拖到 0 即关闭。

## 没声音

1. 托盘菜单里确认显示「已连接」
2. 打开 Windows 的声音设置，确认默认播放设备是正确的那个
3. 托盘菜单 → 打开日志文件夹，看日志

日志超过 30 天或 512KB 自动清理。

## 一直显示「连接中」

接收端需要从局域网回连本机做时钟同步，本程序必须在 Windows 防火墙里有入站放行。

程序启动时会自己检测这一项。缺放行时：

| 步骤 | 操作 |
|---|---|
| 1 | 托盘菜单 → 修复连接问题 |
| 2 | 同意弹出的管理员请求 |

也可以手动补上：

| 步骤 | 操作 |
|---|---|
| 1 | 打开「Windows 安全中心」 |
| 2 | 进入「防火墙和网络保护」 |
| 3 | 点「允许应用通过防火墙」 |
| 4 | 在列表里找到 AirPlay Bridge，勾选「专用网络」 |

列表里没有 AirPlay Bridge 时，点「更改设置」→「允许其他应用」→「浏览」，
选中本程序加入列表后再勾选「专用网络」。

## 已知限制

- 未安装虚拟声卡时，电脑扬声器会同时出声
- 延迟和音质改档需要重连一次
- 仅支持 Windows
- 断连后有数秒静音，随后自动恢复
