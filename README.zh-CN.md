# AirPlay Bridge

<p align="center">
  <img src="src/icons/preview_connected.png" width="128" alt="AirPlay Bridge">
</p>

[English](README.md) · **中文**

把 Windows 的系统声音实时串流到 AirPlay 2 设备，跑在托盘里。HomePod OS 27
之后 TuneBlade 失效的免费开源替代，适配 HomePod、Apple TV 与其他接收端。

## 📦 安装

从 [Releases](https://github.com/RiverFlowsInUUU/AirPlay-Bridge/releases/latest)
下载 `AirPlay-Bridge-Setup-vX.Y.Z.exe` 双击安装。Windows 10 / 11，64 位。

装到 `Program Files\AirPlayBridge`，自带运行库；**升级不用重新配置**——
网络放行和开机自启都跟着这个位置走。首次运行 Windows 可能拦一次，点
「更多信息」→「仍要运行」。

### 🔊 什么时候需要虚拟声卡

| 你的情况 | 装不装 |
|---|---|
| 电脑有会出声的扬声器或耳机 | **装**，否则电脑和音箱同时响（差约 200ms，像回声） |
| 有声卡，但没接任何东西 | 不用，本来就没人听 |
| 系统里一个播放设备都没有 | **装**，否则没有可采集的端点 |

装 [VB-Audio Virtual Cable](https://vb-audio.com/Cable/)（免费，装完重启）。
连接时程序把默认设备切到它，系统声音只送到 AirPlay 设备。
虚拟声卡不影响串流内容——两种方式送去设备的音频完全一样。

## 🚀 首次运行

- 询问界面语言、是否开机自启（各只问一次）
- 扫描局域网并连接找到的设备，同时检查防火墙放行（缺了一键修复）

## ✨ 特性

**音频与连接**

- 🆓 免费开源（Apache-2.0）
- 🎵 AirPlay 2 安全配对（兼容 AirPlay 1）—— HomePod、Apple TV 等
- 🎚 无损 16-bit/44.1 kHz；延迟（100–300ms）、音量、音质、待机全可调
- 💪 高负载抗爆音 —— 音频线程走 MMCSS Pro Audio，Win11 后台仍保持 1ms 时钟

**可靠性**

- 🔄 自动重连 —— 掉线、设备换 IP、被其他设备抢占都能回来
- ⏰ 睡眠唤醒 —— 电脑睡醒后自行恢复
- 🛟 强杀安全 —— 下次启动自动恢复音频设备与静音状态
- 💾 配置原子写入，文件损坏时自动从备份恢复
- 🩺 采集看门狗 —— 采集设备被拔或被占用时自动回退/重连

**日常使用**

- 🔎 自动发现设备，🙈 列表里可隐藏不想看到的
- 🔇 连接时静音本机 —— 串流中换了默认设备，恢复也找对端点
- 😴 无声音时待机 —— 设备熄屏，一有声音立刻回来
- 🖥 开机自启、记住设置、同一时间只运行一个实例
- 🌐 中英文界面；ℹ️「关于」可查版本与检查更新

## 🖱 使用

托盘图标左键或右键都能打开菜单：

```
✓ 已连接
  <设备名> / <设备 IP>
────────────────
  断开
  设备  ›        ← 扫到的设备、重新扫描、隐藏设备、采集来源
  延迟  200ms  ›
  音量  50%  ›
  音质  至臻  ›
────────────────
  更多设置  ›     ← 连接诊断、无声音时待机、静音本机输出、
                   开机自启、语言、日志
  关于
────────────────
  退出
```

网络放行正常时，点「更多设置 › 连接诊断」会直接告诉你不需要处理。

## 🎛 可调项

| 项 | 档位 | 无极滑块 | 生效 |
|---|---|---|---|
| 延迟 | 130 / 150 / **200** / 250 / 300 ms | 100–300 | 重连后 |
| 音量 | 关 / 30% / 50% / 70% / 100% | 0–100 | 立即 |
| 音质 | 快速 / 标准 / 高 / 极高 / 至臻 | 0–100 | 重连后 |
| 无声音时待机 | 5 / 10 / 15 / 20 秒 | 0–20 | 立即 |

粗体是默认值。延迟低于 250ms 有爆音风险，250ms 是实测最稳的一档，
130ms 属实验区间；待机拖到 0 即关闭。

## 🔇 没声音

1. 托盘菜单确认显示「已连接」
2. 打开 Windows 声音设置，确认默认播放设备正确
3. 托盘菜单 → 更多设置 → 日志

## ⏳ 一直显示「连接中」

接收端要回连本机做时钟同步，程序必须在防火墙里有入站放行。启动时会自检：

| 步骤 | 操作 |
|---|---|
| 1 | 托盘菜单 → 更多设置 → 连接诊断 |
| 2 | 同意弹出的管理员请求 |

手动补上：Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙 →
AirPlay Bridge → 勾选「专用网络」。没有就点「允许其他应用」→「浏览」添加。

## ⚠️ 已知限制

- 没装虚拟声卡时，声音仍留在电脑的输出设备上（默认静音，可在菜单关掉）
- 延迟和音质改档需要重连一次
- 仅支持 Windows
- 断连后有数秒静音，随后自动恢复
