# AirPlay Bridge

  <img src="src/icons/preview_connected.png" width="128" alt="AirPlay Bridge">

[English](README.md) · **中文**

把 Windows 的系统声音实时串流到 AirPlay 2 设备，跑在托盘里。

TuneBlade 在 HomePod OS 27 失效后的替代方案。

## 📦 安装

从 [Releases](https://github.com/RiverFlowsInUUU/AirPlay-Bridge/releases/latest)
下载 `AirPlay-Bridge-Setup-vX.Y.Z.exe`，双击安装。**不用装虚拟声卡**，装上就能用。

装到固定位置（`Program Files\AirPlayBridge`）。**以后升级不用重新配置** ——
网络放行和开机自启都跟着这个位置走，换版本也不会失效。

Windows 10 / 11，64 位。安装包自带运行库，不需要单独安装。

> 首次运行 Windows 可能拦一次，点「更多信息」→「仍要运行」。

### 🔊 什么时候才需要虚拟声卡

[VB-Audio Virtual Cable](https://vb-audio.com/Cable/)（免费，装完需重启）是用来
让声音**不走电脑扬声器**的：连接时程序把系统默认播放设备切到虚拟声卡、从那里采集，
电脑自己的扬声器就收不到信号了。

**电脑有扬声器或耳机会让你听见时才需要它** —— 笔记本自带喇叭，或者台式机
往耳机口插了音箱。不装也能串流，而且程序默认会静音本机的输出设备，
一般来说不会听到两份；虚拟声卡的好处是「电脑安静」由声音的走向保证，
而不是靠那个静音。

**没有可听的输出设备时就不用装**：声卡只有一个假的或远程回放端点、
迷你主机没有喇叭、或者扬声器长期关掉的机器，直接装软件本身即可。

只有一个例外 —— 系统里**一个播放设备都没有**（全部禁用）时，程序没有可采集的
端点，这时虚拟声卡就是那个端点。

> 虚拟声卡不影响串流内容 —— 两种方式送去设备的音频完全一样。

## 🚀 首次运行

- 询问界面语言（只问一次，之后可在菜单里改）
- 询问是否开机自动启动（只问一次，之后可在菜单里改）
- 扫描局域网并连接找到的设备
- 检查网络放行是否有效，失效时提示一键修复


## 🔊 声音输出

连接后，声音只从 AirPlay 设备出，电脑保持安静，断开时自动还原。

## ✨ 特性

- 🔎 自动发现局域网内的设备
- 🔄 断线自动重连，设备换 IP 也能找回
- 🛟 被强杀后，下次启动自动恢复音频设备
- 🌐 界面支持中文与英文
- 🎚 延迟 / 音量 / 音质 / 无声音时待机 / 采集设备可调
- 😴 无声音时待机：长时间没声音时断开让设备熄屏，一有声音立刻回来
- 🖥 开机自启，记住上次设置
- ℹ️ 「关于」里可查看版本并检查更新
- 🔇 连接时自动静音电脑扬声器，不再和 AirPlay 设备同时出声
- 🙈 设备列表可隐藏不想看到的设备
- 1️⃣ 同一时间只允许运行一个，避免互相打断播放

## 🖱 使用

托盘图标左键或右键都能打开菜单。

```
✓ 已连接
  <设备名>
  <设备 IP>
────────────────
  断开
  设备  ›
     <设备名>            ← 扫到的设备直接列在这里
     重新扫描
     ──────────────
     隐藏设备  ›
     采集设备  ›
  延迟  200ms  ›
  音量  50%  ›
  音质  至臻  ›
────────────────
  更多设置  ›
     连接诊断
     无声音时待机  ›
     静音本机输出
     开机自启
     语言  ›
     日志
  关于
────────────────
  退出
```

网络放行正常时，点「更多设置 › 连接诊断」会直接告诉你不需要处理。

## 🎛 可调项

| 项 | 范围 | 生效 |
|---|---|---|
| 延迟 | 130 – 300 ms，5 档 + 无极滑块（100–300） | 重连后 |
| 音量 | 0 – 100%，关 / 30% / 50% / 70% / 100% + 无极滑块 | 立即 |
| 音质 | 0 – 100%，5 档 + 滑块 | 重连后 |
| 无声音时待机 | 0 – 20 秒，4 档 + 无极滑块（0 = 关闭） | 立即 |

延迟档位：130 / 150 / 200 / 250（推荐）/ 300 ms。低于 250 ms 有爆音风险，130 ms 属实验区间。

音量档位：关 / 30% / 50% / 70% / 100%。

音质档位：快速 / 标准 / 高 / 极高 / 至臻（默认）。

待机档位：5 / 10 / 15 / 20 秒（5 秒默认）；滑块为 0 – 20 秒无极调节，拖到 0 即关闭。

## 🔇 没声音

1. 托盘菜单里确认显示「已连接」
2. 打开 Windows 的声音设置，确认默认播放设备是正确的那个
3. 托盘菜单 → 更多设置 → 日志


## ⏳ 一直显示「连接中」

接收端需要从局域网回连本机做时钟同步，本程序必须在 Windows 防火墙里有入站放行。

程序启动时会自己检测这一项。缺放行时：

| 步骤 | 操作 |
|---|---|
| 1 | 托盘菜单 → 更多设置 → 连接诊断 |
| 2 | 同意弹出的管理员请求 |

手动补上：「Windows 安全中心」→「防火墙和网络保护」→「允许应用通过防火墙」→
找到 AirPlay Bridge → 勾选「专用网络」。列表里没有时，先点「允许其他应用」→「浏览」添加。

## ⚠️ 已知限制

- 未安装虚拟声卡时，声音仍会留在电脑的输出设备上（默认会静音本机，可在菜单关掉）
- 延迟和音质改档需要重连一次
- 仅支持 Windows
- 断连后有数秒静音，随后自动恢复
