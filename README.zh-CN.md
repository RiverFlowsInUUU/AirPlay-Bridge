# AirPlay Bridge

  <img src="src/icons/preview_connected.png" width="128" alt="AirPlay Bridge">

[English](README.md) · **中文**

把 Windows 的系统声音实时串流到 AirPlay 2 设备，跑在托盘里。

TuneBlade 在 HomePod OS 27 失效后的替代方案；
也是 WinAirCast、ToneRelay、SoundHop 之外一个免费开源的选择。

## 📦 安装

从 [Releases](https://github.com/RiverFlowsInUUU/AirPlay-Bridge/releases/latest)
下载 `AirPlay-Bridge-Setup-vX.Y.Z.exe`，双击安装。**不用装虚拟声卡**。

Windows 10 / 11，64 位。安装包自带运行库，装到 `Program Files\AirPlayBridge`——
**以后升级不用重新配置**，网络放行和开机自启都跟着这个位置走。

> 首次运行 Windows 可能拦一次，点「更多信息」→「仍要运行」。

### 🔊 什么时候才需要虚拟声卡

电脑有会出声的扬声器或耳机时，装
[VB-Audio Virtual Cable](https://vb-audio.com/Cable/)（免费，装完需重启）。

连接时程序把默认播放设备切到虚拟声卡，系统声音只送到 AirPlay 设备。

没有可听的输出设备就不用装 —— 假的或远程回放端点、无喇叭的迷你主机、
常关的扬声器。程序照样串流，并默认静音本机。

例外：系统里一个播放设备都没有时，没有可采集的端点，需要虚拟声卡补一个。

> 虚拟声卡不影响串流内容 —— 两种方式送去设备的音频完全一样。

## 🚀 首次运行

- 询问界面语言、是否开机自启（各只问一次）
- 扫描局域网并连接找到的设备
- 检查网络放行，失效时提示一键修复

## ✨ 特性

**音频与连接**

- 🆓 免费开源（Apache-2.0）
- 🎵 AirPlay 2 安全配对（兼容 AirPlay 1）—— HomePod、Apple TV
  及其他 AirPlay 接收设备
- 🎚 无损 16-bit/44.1 kHz；延迟（100–300 ms）、音量、重采样品质、
  待机全部可调
- 💪 高负载抗爆音 —— 音频线程走 MMCSS Pro Audio 调度，
  Windows 11 后台也保持 1ms 时钟精度

**可靠性**

- 🔄 自动重连 —— 掉线、设备换 IP、被其他设备抢占都能回来
- ⏰ 睡眠唤醒 —— 电脑睡醒后串流自行恢复
- 🛟 强杀安全 —— 下次启动自动恢复音频设备与静音状态
- 💾 配置原子写入，文件损坏时自动从备份恢复
- 🩺 采集看门狗 —— 采集设备被拔或被占用时自动回退/重连

**日常使用**

- 🔎 自动发现局域网内的 AirPlay 设备 · 🙈 不想看的可隐藏
- 🔇 连接时静音本机 —— 即使串流中换了默认设备，恢复也找对端点
- 😴 无声音时待机 —— 设备熄屏，一有声音立刻回来
- 🖥 开机自启、记住设置、同一时间只运行一个实例
- 🌐 中英文界面 · ℹ️ 「关于」里可查版本与检查更新

## 🖱 使用

托盘图标左键或右键都能打开菜单。

```

  <设备名>
  <设备 IP>
────────────────
  断开
  设备  ›
     <设备名>            ← 扫到的设备直接列在这里
     重新扫描
     ──────────────
     隐藏设备  ›
     采集设备  ›
  延迟  200ms  ›
  音量  50%  ›
  音质  至臻  ›
────────────────
  更多设置  ›
     连接诊断
     无声音时待机  ›
     静音本机输出
     开机自启
     语言  ›
     日志
  关于
────────────────
```

网络放行正常时，点「更多设置 › 连接诊断」会直接告诉你不需要处理。

## 🎛 可调项

| 项 | 档位 | 无极滑块 | 生效 |
|---|---|---|---|
| 延迟 | 130 / 150 / **200** / 250 / 300 ms | 100–300 | 重连后 |
| 音量 | 关 / 30% / 50% / 70% / 100% | 0–100 | 立即 |
| 音质 | 快速 / 标准 / 高 / 极高 / 至臻 | 0–100 | 重连后 |
| 无声音时待机 | 5 / 10 / 15 / 20 秒 | 0–20 | 立即 |

粗体是装好后的默认值。延迟低于 250 ms 有爆音风险，250 ms 是实测最稳的一档，
130 ms 属实验区间；待机拖到 0 即关闭。

## 🔇 没声音

1. 托盘菜单里确认显示「已连接」
2. 打开 Windows 声音设置，确认默认播放设备正确
3. 托盘菜单 → 更多设置 → 日志

## ⏳ 一直显示「连接中」

接收端需要回连本机做时钟同步，所以程序必须在 Windows 防火墙里有入站放行。
启动时会自检，缺放行时：

| 步骤 | 操作 |
|---|---|
| 1 | 托盘菜单 → 更多设置 → 连接诊断 |
| 2 | 同意弹出的管理员请求 |

手动补上：「Windows 安全中心」→「防火墙和网络保护」→「允许应用通过防火墙」→
AirPlay Bridge → 勾选「专用网络」。列表里没有时，点「允许其他应用」→「浏览」添加。

## ⚠️ 已知限制

- 未安装虚拟声卡时，声音仍留在电脑的输出设备上（默认静音，可在菜单关掉）
- 延迟和音质改档需要重连一次
- 仅支持 Windows
- 断连后有数秒静音，随后自动恢复
